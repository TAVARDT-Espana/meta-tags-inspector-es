# Inspector de Meta Tags y Open Graph

[![Inspector Meta Tags](https://img.shields.io/badge/TAVARDT-Meta%20Tags-5b3cf5.svg)](https://tools.tavardt.com/es/analizador-meta-tags-seo/)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Revision tecnica de metadatos HTML, analisis de longitud de titulos y descripciones, tarjetas para redes sociales y directivas de rastreo.

Desarrollado y mantenido por el area de tecnologia web y posicionamiento de **TAVARDT**.

***

## Capacidades de Auditoria de Metadatos y Redes Sociales

* **Inspeccion de Titulo y Meta Descripcion**: Analisis de extension optima de la etiqueta title (30 a 60 caracteres) y meta description (120 a 160 caracteres).
* **Marcado Open Graph**: Comprobacion de parametros og:title, og:description, og:image, og:url y og:type.
* **Tarjetas para Redes Sociales**: Verificacion de Twitter Cards y compatibilidad multiplataforma.
* **Directivas de Indexabilidad**: Control de etiquetas robots y enlaces canonicos.
* **Calificacion de Calidad de Fragmento**: Puntuacion objetiva de 0 a 100 con guia paso a paso de optimizacion.

***

## Instalacion y Uso

Requiere Python 3.8 o superior sin dependencias externas.

```bash
git clone https://github.com/TAVARDT-Espana/meta-tags-inspector-es.git
cd meta-tags-inspector-es
python meta_inspector.py ejemplo.es
```

Para formato estructurado JSON:

```bash
python meta_inspector.py ejemplo.es -json
```
